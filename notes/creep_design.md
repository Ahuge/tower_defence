# Creep Visual Design — Per-Faction Creature Sets

Each faction has a core creature identity. Every creep type is a variant of that faction's creature, visually distinct by silhouette, color accent, and size. Cross-faction recognition cues help identify creep TYPES regardless of faction (e.g. all fast creeps are lean/elongated, all armored are bulky/wide).

## Cross-Faction Recognition Cues

These visual patterns repeat across all factions so players learn to read creep types:

| Creep Type | Silhouette Cue | Size | Movement Feel |
|------------|---------------|------|---------------|
| Standard | Medium, balanced proportions | 1x | Normal walk |
| Fast | Lean, elongated, low profile | 0.8x | Quick stride |
| Armored | Wide, bulky, hunched | 1.2x | Heavy stomp |
| Swarm | Tiny, simple shape | 0.5x | Skittery |
| Healer | Distinct head/hat, staff/glow | 1x | Floating step |
| Boss | Large, imposing, crowned/horned | 1.8x | Slow lumbering |
| Group | Same as Standard but clustered | 0.9x | Marching |
| Splitter | Unstable outline, seams visible | 1.1x | Wobbling |
| Shielded | Bubble/barrier around body | 1x | Protected walk |
| Evasive | Wispy, translucent, agile pose | 0.9x | Darting |
| Regenerator | Pulsing body, organic feel | 1.2x | Steady trudge |
| Flying | Wings/hover, elevated shadow | 1x | Gliding |
| Mage (all 4) | Robed figure, staff, glowing hands | 1x | Floating |

## Sprite Sheet Layout

Each faction gets one creep spritesheet:
- **16 columns** (one per creep type)
- **4 rows** (walk cycle: frame 0, 1, 2, 3)
- **Frame size**: 32×32 pixels (slightly larger than TILE_SIZE for detail, scaled down in-game)
- Total per faction: 16 × 4 = 64 frames at 32×32 = 512×128 per sheet

Plus a **Mage variant sheet** (shared across all mage types):
- Same 4 columns (iron/haste/mist/heal) × 4 walk frames
- Mage robes are the same silhouette, differentiated by:
  - **Iron**: gray/metallic tint, shield icon
  - **Haste**: blue tint, speed lines
  - **Mist**: white/transparent tint, fog
  - **Heal**: green tint, cross/plus icon

## Implementation Notes

- Each game randomly selects a faction's creep set (or matches the wave theme)
- Mage creeps always use the same robed silhouette with type-specific coloring
- Boss sprites are 2× scale of standard
- Swarm sprites are 0.5× scale
- Status effects applied via Phaser tint (setTint) on the sprite
- Walk cycle: 4 frames at ~200ms per frame
- Direction: right-facing sprites, flipped horizontally when moving left
