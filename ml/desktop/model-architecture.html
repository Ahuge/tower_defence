How It Works

For each candidate cell, the model scores how likely Alex would place a tower there given the current board state.

Training: positive examples are cells where Alex (or a winning bot) actually placed a tower. Negative examples are 5 random other cells from the same board state. The model learns to distinguish good placements from random ones.

Inference: StrategistBrain evaluates all candidate cells through the model, picks the highest-scoring cell above a threshold (0.3). If no cell scores high enough, it falls back to hand-coded logic.

What's missing: the model sees where towers go but not when in the wave cycle, what creeps are coming, or how much gold is available. It also can't see the path — it doesn't know if a cell blocks the maze. These are the main limitations.

Per-faction: each faction gets its own model because placement patterns are faction-specific (void gamblers cluster at entry, psionic probes interleave with mesmers, etc.). A single shared model would blur these patterns.

Training data: 897,947 examples in v5 — synthetic bot wins, expert replays (×10 weight), augmented expert (×3), procgen patterns (×2), directed search (×5).
